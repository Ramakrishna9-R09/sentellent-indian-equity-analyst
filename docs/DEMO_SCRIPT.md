# Reviewer demo script

1. Visit the AWS URL and sign in with either configured Google Test User.
2. Search for RELIANCE or TCS and follow it.
3. Show the ingestion status transition and open a source record.
4. Ask: "What is the sentiment on this stock this week?" Open the inline citations and source excerpts.
5. State: "I am a conservative, dividend-focused investor and avoid high-debt companies."
6. Open the profile page to show the sourced memory fact.
7. Ask for profile-matched candidates. Show hard exclusions, cited one-line rationale, INR formatting, and any explicit data gaps.
8. Open GitHub Actions and AWS console screenshots to show the automated deployment.
